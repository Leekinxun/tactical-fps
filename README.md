# BREACHLINE

原创网页战术 FPS 原型，支持单人训练与同一局域网内 2–4 名玩家合作对抗 Bot：

- Babylon.js 灰盒训练区，WebGPU 优先并自动回退 WebGL2
- 第一人称移动、跳跃、蹲下、冲刺、鼠标锁定与自动暂停
- BR-4 卡宾枪视角模型、射速限制、弹药、换弹、命中区与训练目标
- 数据驱动的 6 类武器目录
- 手枪局限制、胜负奖金、连败档位、击杀奖励、购买与退款规则
- 4 名 Bot 的视线、听觉、反应延迟、追踪最后已知位置和交战状态
- `BUY / LIVE / ROUND_END` 多回合比赛流程，先取得 7 胜结束比赛
- 购买菜单、实时比分、阶段计时、经济记录和比赛结果页
- Recast 导航网格与战术点回退路径，Bot 卡住 2 秒后自动恢复
- 死亡掉枪、`E` 拾取、`G` 丢弃、弹匣/备弹状态守恒与回合末清理
- Bot 小队共享钱包、手枪局限制、混合买枪规划和单次团队奖励
- 五位房间码创建/加入、远端玩家插值显示与掉线自动重连
- WebSocket 权威服务器统一裁定移动、射速、弹药、换弹、墙体遮挡、伤害、经济、回合和比赛结果
- 多人死亡掉枪、`E` 竞争拾取和 `G` 主动丢弃，唯一实体 ID 防止重复获得
- 15 秒断线状态保留、协议版本校验、消息限频与全员再战投票
- Vitest 规则测试、TypeScript 严格检查、ESLint 与生产构建

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:4173`。点击“开始演训”后使用 WASD、鼠标、空格、C、Shift、R 和 Esc。

## 局域网联机

在作为房主的电脑上启动网页与房间服务器：

```bash
npm run dev:multiplayer
```

房主浏览器打开 `http://localhost:4173`；同一 Wi-Fi 或有线局域网中的其他玩家打开 `http://<房主局域网IP>:4173`。一名玩家选择“创建房间”并分享五位房间码，其余玩家选择“加入房间”。

联机服务器默认监听 `8787` 端口，网页开发服务器监听 `4173` 端口；操作系统防火墙需要允许这两个端口的局域网访问。也可以分别运行：

```bash
npm run multiplayer-server
npm run dev
```

当前联机版同步玩家、Bot、生命、护甲、武器、弹药、掉落物、经济和回合。掉落武器由服务器统一创建与回收；多名玩家同时拾取时只有最先通过服务器校验的玩家能够获得。


## 容器

```bash
docker build -t breachline .
docker run --rm -p 8080:80 breachline
```

浏览器打开 `http://localhost:8080`。该镜像同时运行静态网页、WebSocket 房间服务器与反向代理，不需要额外暴露 `8787` 端口。
